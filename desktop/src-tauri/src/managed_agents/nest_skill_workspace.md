# Workspace conventions

The Buzz Nest is the current working directory. Do not search `$HOME` or `/` for another workspace.

| Directory | Use |
|---|---|
| `REPOS/` | Source checkouts |
| `RESEARCH/` | Findings and cited evidence |
| `GUIDES/` | Reusable runbooks |
| `PLANS/` | Active plans |
| `WORK_LOGS/` | Timestamped activity records |
| `OUTBOX/` | Material prepared for external readers |
| `.scratch/` | Disposable temporary work |

Use `ALL_CAPS_WITH_UNDERSCORES.md` filenames. Knowledge files use YAML frontmatter with a quoted title, lowercase-hyphenated tags, status (`active`, `superseded`, `stale`, or `draft`), and creation date. Check local research and guidance before external search, cite claims with paths or links, and do not silently overwrite existing work.
