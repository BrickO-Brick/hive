# Buzz Project Orbit

An isolated interaction prototype for exploring project cubes and task noodles
in Buzz. It reuses the Berd project cube renderer, model, textures, and agent
avatars.

The prototype includes:

- Manual 3D cube rotation with noodles that adapt to the visible cube edges.
- Draggable task noodles and task detail interactions.
- A pannable multi-project canvas.
- A swipeable Projects view with glass task cards and expandable task details.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Use `npm run build` for a production build.
